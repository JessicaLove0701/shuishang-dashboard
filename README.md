# 水上业务工作台

油品 / 水上业务的内部数据看板，纯静态单页（`index.html` + `data.json`），无构建步骤。

## 页面模块

| 模块 | 说明 |
|---|---|
| 工作台首页 | 概览入口 |
| 网价查询 | 16 城中石油柴油网价，卓创 / 金联创双站对照，点城市看近月走势 |
| 应急采购批次 | 批次台账（原云端同步，迁移后为本机浏览器存储） |
| 国际油价 | WTI / 布伦特近 3 个月日度走势 + 未来 5 个工作日预测 |
| 各省发改委价格 | 沿海各省成品油最高批发 / 零售限价 |
| 需求反馈 | 需求登记（同上，本机存储） |

## 数据说明

- 国际油价：历史日度取自 FRED 公开数据（`DCOILWTICO` / `DCOILBRENTEU`）；FRED 发布延迟约 1 周，最近交易日由公开报道的收盘价补齐，口径差异在页面内标注。
- 各省油价：各省发改委公布的最高批发 / 零售限价。
- 网价：卓创资讯、金联创每日「中石油」企业报价。
